# Inspira Más

Landing page oficial de Inspira Más, una iniciativa que acompaña a jóvenes a descubrir oportunidades, fortalecer su perfil y prepararse para alcanzarlas.

Sitio publicado: https://inspira-mas.mparaujo1405.chatgpt.site/

## Desarrollo local

```bash
pnpm install
pnpm dev
```

## Compilación
